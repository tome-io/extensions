# Readio third-party extensions

This repository is reserved for reviewed community extensions that are installed manually by
repository URL. They are not bundled with Readio and are not presented through an in-app catalog.

Each extension owns its manifest, configuration schema, and integrity-checked JavaScript bundle.
The Readio host runs bundles in a sandbox and mediates network and storage access according to the
manifest permissions.

Third-party providers that have not been reviewed by Readio should be published from their own
repositories rather than from the Readio organization.
