# Readio third-party extensions

This repository contains extensions that are installed manually by repository URL. They are not
bundled with Readio and are not presented through an in-app catalog.

Each extension owns its manifest, configuration schema, and integrity-checked JavaScript bundle.
The Readio host runs bundles in a sandbox and mediates network and storage access according to the
manifest permissions.

Install the Z-Library provider with:

`https://github.com/readoi/extensions/tree/main/third-party/zlibrary`
